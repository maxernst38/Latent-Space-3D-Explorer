# Latent Space Explorer

Latent Space Explorer is a tool for visualizing and interacting with latent spaces in machine learning models. It helps users understand and analyze the structure of high-dimensional data representations.

## Features

- Visualize latent spaces in 3D
- Interactively explore data points and clusters

## Installation

```bash
git clone https://github.com/yourusername/latent_space_explorer.git
cd latent_space_explorer
pip install -r requirements.txt
```

## Usage

Place datasets in datasets/ folder to see them in the UI.

```bash
streamlit run app.py
```
